# Security, Privacy and Fairness

Resumes contain highly sensitive identity, employment, education and contact information.

## Production controls
Authentication, vacancy-scoped RBAC, encryption, secrets management, malware-safe document parsing, audit logs, retention/deletion workflows and restricted export.

## Hiring fairness
Do not use names, photos, addresses or proxies for protected characteristics in scoring. Scores must support—not replace—human review. Real use requires job-related validation, fairness testing, accessibility review and legal/compliance assessment.
